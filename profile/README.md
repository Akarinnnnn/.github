## Programming languages

I have tried several programming languages since 2019. Eventually, **C#** defined my taste 6 years ago and has been my favorite programming language since.

An interesting fact is that when I was a 12-year-old primary school student, I already began writing non-standard C for a science and technology competition. A typical Chinese student experience, right? I still remember the kit manufacturers' names: 中鸣 (spelled Joinmax?) and ETR虚拟机器人 (though I call it **NTR**虚拟机器人). 如果这两个名字唤起了你的记忆，搞不好我们俩在同一个赛场待过。不要盒我555

Joinmax uses standard GCC as its compiler, which I appreciate. I guess it emits ARMv6 PE binaries. But the NTR uses its self-developed toy frontend with bytecode emission — a C-like frontend that does not support preprocessor directives (`$include`, or even `#if/#elif/#else/#endif`). The manufacturer recommends that players program using a WYSIWYG flowchart designer, but it's about as expressive as assembly language. The flowchart designer's codegen is a 典中典的 copy-paster, which made me finally decide to use the 嘉豪-style code editor. Still, using an integrated code editor without any IntelliSense gave me some advantages over players using flowcharts... What can I say? Flow OUT!
